# VerifyRank methane case

Derived evaluation inputs, frozen predictions, controlled masking analyses and figure sources for **Verification-aware evaluation of ranked environmental monitoring: a reusable framework with a methane case study**. The sole human contributor to this artifact is **junjiezhang**. Original environmental observations are attributed to Carbon Mapper and the cited provider archive; they are not claimed as this contributor's original measurements.

The reusable MIT software is maintained separately at [williamjay1/verifyrank](https://github.com/williamjay1/verifyrank). This case repository contains provider-derived data with source-specific terms. See [DATA_TERMS.md](DATA_TERMS.md) and [CODE_LICENSE.txt](CODE_LICENSE.txt). There is no new Zenodo DOI for this artifact.

## What the case demonstrates

An archive can support a verified-subset comparison without identifying the performance of frozen recommendations on the full candidate inventory. Sharing the same unknown reference across policies narrows a completion range; missing qualified follow-up can still prevent selecting a winner. Unique-reference priorities can guide verification when actual records are recoverable. A new observation cannot recover a nonexistent historical scene.

The main comparison uses two GAO Permian campaigns, an accepted-detection endpoint and frozen history inputs. Source anchors approximate emitting locations, not verified equipment identities. Qualified nondetection does not establish physical zero emissions. Assumed availability delays are archive scenarios, not reconstructed public access. Controlled masking hides existing recorded outcomes; it does not generate new field observations or validate the actual missingness mechanism. Hypothetical costs and recovery probabilities are not measured flight or annotation expenses.

## Sources, attribution and changes

**Source: Carbon Mapper.** The 2023 catalogue was frozen from the public service on 5 October 2026. The 2024 source is [Cusworth's archive, DOI 10.5281/zenodo.17862304](https://doi.org/10.5281/zenodo.17862304), associated with [Duration of super-emitting oil and gas methane sources](https://doi.org/10.1038/s41467-026-68804-7). That independent original archive is marked CC BY 4.0. The mixed-year derived panel retains the applicable Carbon Mapper conditions for its 2023 information.

Changes made by this project include quality qualification, chronological fixed-anchor grouping, fixed future windows, history-only features, ranking weights, masking, coefficient aggregation and derived summaries/figures. `SOURCE_MANIFEST.json` records input and artifact hashes and public paths. Original API bodies, imagery, provider notebooks, proprietary facility information, signed URLs, credentials, machine-specific raw manifests and third-party full texts are not included. The original data remain accessible through the cited providers; this repository does not replace their archive.

Tests assess implementation properties and numerical agreement; they do not physically validate catalogue labels or establish that nondetection means zero emissions.
